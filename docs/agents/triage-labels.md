# Triage Label Names

The skills use five triage roles. This file maps each role to the GitHub label name this project expects.

Before you apply a label, make sure it exists in GitHub. Create a missing label with the name in the right-hand column.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

When a skill mentions a role (for example, “apply the AFK-ready triage label”), use the matching label name from this table.

Update the right-hand column if the project changes its GitHub label names.
